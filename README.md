# Billions 项目介绍
数十亿网络 是一个基于区块链的数字身份验证平台，旨在为人类和人工智能（AI）提供隐私优先的身份验证解决方案。它通过零知识证明（Zero-Knowledge Proof, ZKP）技术（特别是 Circom 技术），在不依赖生物识别数据（如虹膜或指纹扫描）的情况下实现安全、可扩展的身份验证。

融资情况：目前公开信息中，Billions Network 的具体融资细节尚未完全披露。
